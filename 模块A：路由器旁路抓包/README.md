## 1. 问题来源

以真实玩家 Miffy 的账号为例：**26 个盒子、593 只精灵，其中 187 只异色、84 只炫彩**。游戏没有导出能力，确认资产分布只能逐页浏览。数据已经存在，但不可查询。

## 2. 目标与边界

- **不接触游戏进程**：不注入、不改内存、不发包
- **不增加终端负担**：PC / iPad / 手机均无需安装驱动或证书
- **数据归用户**：默认不同步；交付物只含派生字段，原始帧与会话密钥不进入产物

## 3. 行业常见方案

- Windows：[Npcap](https://nmap.org/npcap/) / [WinPcap](https://www.winpcap.org/) 配合 [Wireshark](https://www.wireshark.org/)，需内核驱动与管理员权限
- 移动端：[Charles](https://www.charlesproxy.com/)、[HttpCanary](https://httpcanary.cn/) 依赖证书与系统 VPN；[PCAPdroid](https://github.com/GrenderG/PCAPdroid) 可免 root 抓包；root / 越狱后可用 [tcpdump](https://www.tcpdump.org/)
- 同场景项目：[ROCO-Nearby-Pet](https://github.com/Vicuna1277/ROCO-Nearby-Pet)、[roco-pve-viewer](https://github.com/Evenstar-tools/roco-pve-viewer) 聚焦单机单端展示

## 4. 方案局限

| 维度 | 问题 |
|---|---|
| 安全性 | 内核驱动需管理员权限；代理需装证书、明文经第三方进程；root / 越狱破坏沙箱 |
| 多设备 | 每台设备单独装、单独配，时间线对不齐，导出格式不统一 |
| 数据复用 | 各工具只解决单点问题，原始数据无法沉淀为统一数据源 |

## 5. 技术路径

把抓包点从终端设备迁移到**网络必经点——路由器**：

1. `br-lan` 开混杂模式，BPF 严格过滤 `tcp port 8195 and host <游戏设备IP>`
2. 采集层零解析、只落 pcap；解析层离线回放，完成 TCP 重组、会话解密与 opcode 门控
3. 会话密钥 `0x1002` 只在建连瞬间下发，采集须先启动，再让设备断网 3 秒重连
4. 输出层只保留白名单派生字段，默认不同步

底层已在**新路由 D2（Newifi D2）+ Padavan 固件**上验证，端点侧零安装。

## 6. 关键挑战与应对

| 挑战 | 应对 |
|---|---|
| 采集与解析耦合导致战斗帧丢失 | 先落 pcap，离线回放解析 |
| `0x1002` 仅在建连瞬间下发 | 采集先行，断网 3 秒重连触发密钥 |
| 丢段与 1044 心跳噪声淹没战斗帧 | `gap_timeout` 5s → 10s；实时过滤噪声，原始 pcap 留档可恢复 |
| 多设备与同 IP 双开 | 按 IP 分发，`game_id` 区分会话 |
| 固件重挂导致 `/opt` 回落 40MB | 固化启动脚本与 nvram，备一键恢复 |
| 出战栏 / 场景宝箱与背包盒混淆 | 盒位判别式 + 抓包队伍序列还原显示顺序 |

## 7. 结果与价值

- **资产可见性**：26 盒 / 593 只 / 187 异色 / 84 炫彩，玩家核心资产可查询
- **链路复用性**：PC + iPad + 手机统一采集；单份 pcap 可派生战斗、背包、图鉴等多套应用
- **扩展成本**：新增应用只写离线解析器，不改抓包链路与终端配置
- **数据边界**：原始帧与会话密钥不出本机，交付物仅含脱敏派生字段

## 8. Demo 入口：`live.html`

`live.html` 是**路由器 live 监控页的离线版本**，不是介绍页：

- 页面形态与真实 live 一致：顶部状态与统计卡、设备筛选、左侧滚动事件流、右侧战斗 / 背包 / 蛋 / Opcode / 未知字段 / 连接诊断面板
- 真实环境由路由器采集端提供契约事件；**演示环境拿不到抓包，所以点击「回放 pcap」把离线事件流喂进同一套界面**
- 日志遵循上级项目事件契约：`ts / flow_id / dir / opcode / fields / confidence / event_kind`；点击任意行展开完整 JSON
- 回放过程中右侧同步刷新：精灵对战（4886 M5）、背包（4934 / 6273 / 6277 / 6289）、收蛋（338 + 579）、诊断信息
- 支持设备筛选、暂停滚动、清空、导出 JSONL；「启动采集」在演示环境下提示未连接路由器
