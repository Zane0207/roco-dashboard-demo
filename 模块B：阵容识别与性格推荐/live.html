脱敏检查清单

  • 不加载 / 不上传原始一图流截图，页面只画示意网格与检测框坐标。
  • OCR 文本框只含 text 与 bbox / score，不含玩家昵称、UID、设备 IP。
  • 推荐数据来自 gradRec 离线缓存，只保留性格 / 等级 / 资质，不含账号信息。
  • 图鉴回链只保留 pet_id / 图鉴编号 / 蛋组 / 性别比例 / 赛季，不发起外部请求。
  • 识别结论可整份导出 JSON，便于复核；文件里没有时间戳与原始帧。
