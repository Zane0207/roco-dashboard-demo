# Roco-dashboard-demo · AI 产品经理作品集

把上级项目 `Roco-dashboard`（《洛克王国：世界》异色精灵统计看板）里的真实技术链路，拆成若干**可运行的小 demo**，用于面试展示 AI 产品经理的 **idea 能力** 与 **vibecoding 能力**。

> GitHub 仓库：https://github.com/Zane0207/roco-dashboard-demo
> 当前状态：模块 A 实现中。每个 demo 都从真实项目里来，但只保留可公开、可离线运行的部分。

## 叙事方式

第三人称：「我观察到玩家痛点 → 设计了这些原型 → 用真实数据验证」。

模块 A 的核心取舍：Npcap / 手机抓包把成本落在**每台终端设备**（装驱动、装证书、root / 越狱），路由器方案把成本收敛到**一个网络必经点**——端点零安装，一次采集，多处派生（战斗读取 / 背包管理 / 图鉴收藏）。

## 数据与红线

- 数据来自上级项目真实玩家 **Miffy** 的快照，保留昵称用于叙事，**去掉 UID、源文件名、精确时间戳**
- 不改上级项目任何文件（只读参考）
- 不碰真实凭据 / 线上环境 / 云函数
- 每个模块本地打开即用，零外网依赖
